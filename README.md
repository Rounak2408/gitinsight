## 🚀 Overview

**GitInsight** is an AI-powered Developer Intelligence, Code Analysis, and Career Alignment platform. It parses real GitHub repositories to extract deep engineering metrics, code quality, verified technical evidence, and conducts interactive Voice AI Mock Interviews based on the developer's actual codebase.

---

## ✨ Key Features

- 🤖 **GitAssistant AI Floating Copilot**: Instant Gemini & Claude-level developer assistant that monitors active repository metrics and autonomously guides you to mock interviews and scanning tools.
- 🎙️ **Voice AI Mock Interview**: Interactive real-time audio and text mock interview engine tailored directly to your repository's actual code snippets and CQRS architecture.
- 🔍 **GitHub Profile Analyzer**: Real-time analysis of public repositories, commit patterns, language distributions, and commit velocity.
- ⚡ **Skills Intelligence Radar**: Evidence-based skill proficiency matrix derived from real code, not self-reported tags.
- 💼 **Job Fit & Alignment Matrix**: Real-time matching against engineering roles (e.g., Full Stack TypeScript / Web Engineer).
- 📄 **JD & Resume Analyzer**: Instant skill gap analysis against target company job descriptions.
- 🧭 **Career Roadmap**: AI-generated step-by-step milestones to bridge skill gaps.
- 📊 **Executive Intelligence Reports**: Print-ready and exportable PDF summaries for hiring managers and recruiters.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rounak2408/gitinsight.git
   cd gitinsight
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
